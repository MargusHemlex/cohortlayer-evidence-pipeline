# Public/private boundary

The owner approved publication of this standalone pipeline on **18 October 2026**
after final review. The separate product repository remains **private**, and its
deployment is unchanged.

| Intended public pipeline | Future private engine |
|---|---|
| JSON contracts and adapter interfaces | Real cohort integrations and execution queries |
| Synthetic aggregate fixtures and adapters | Credentials, access agreements and environment settings |
| Fully readable illustrative comparison rule | Proprietary production statistics, scoring and harmonization |
| Illustrative count policy and documented limits | Cohort-specific confidential operating controls |
| Provenance, semantic diff and report rendering | Customer hypotheses, results and query history |
| Tests, schemas, CI and reviewed example reports | Production infrastructure, monitoring and audit logs |
| Public data only after explicit rights review | Restricted or non-redistributable records |

The private-engine column is a future design boundary, not a claim that these
capabilities already exist. The public pipeline must not import the private engine,
reference private submodules, require private package credentials, or contain
bundles generated from private source code. History, fixtures, screenshots and
documentation are included in the publication review.
